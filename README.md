# NEXORA Digital

**Ideas creativas. Soluciones digitales.**

NEXORA Digital es un proyecto de desarrollo web que consiste en crear el sitio web corporativo de una agencia digital ficticia, orientada a ofrecer soluciones creativas y tecnológicas para empresas, emprendedores y pequeños negocios.

El objetivo del proyecto es construir una página web moderna, atractiva, responsive y funcional, aplicando buenas prácticas de desarrollo y separación de responsabilidades.

## Tecnologías

- **PHP:** desarrollo del backend y procesamiento del lado del servidor.
- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño visual, estilos, animaciones y diseño responsive.
- **JavaScript (ES6+):** interactividad y comportamiento dinámico.
- **MySQL:** gestión de datos cuando sea necesario.
- **Git y GitHub:** control de versiones y seguimiento del desarrollo.

## Servicios de la agencia

- Desarrollo web.
- Diseño gráfico.
- Marketing digital.
- Branding e identidad corporativa.

## Objetivos de aprendizaje

Este proyecto también tiene un propósito educativo: fortalecer los conocimientos de desarrollo web mediante la construcción de un proyecto práctico.

Se dará especial atención al aprendizaje de:

- Fundamentos y buenas prácticas de CSS3.
- JavaScript moderno (ES6+).
- Estructuración semántica con HTML5.
- Organización y separación de responsabilidades.
- Principios SOLID aplicados al backend cuando corresponda.
- Diseño responsive y experiencia de usuario.

## Entorno de desarrollo

El proyecto se desarrolla localmente utilizando **XAMPP** y posteriormente se gestionará mediante Git y GitHub.
